# ഹീബ്രു ബൈബിൾ — മലയാള വിവർത്തനം

ഹീബ്രു ബൈബിളിന്റെ (തനാഖ്) വാക്യം-വാക്യം വിവർത്തനം — മൂല
അക്ഷരങ്ങളോട് വിശ്വസ്തമായത്.

## ആദ്യം ഹീബ്രു

ഈ വിവർത്തനം നിങ്ങളെ ഹീബ്രുവിലേക്ക് എത്തിക്കാനുള്ളതാണ് — അതിന്റെ
സ്ഥാനം ഏറ്റെടുക്കാനല്ല. വായിക്കപ്പെടുന്നത് എപ്പോഴും ഹീബ്രുവാണ് —
അതിന്റെ വ്യഞ്ജനങ്ങളും സ്വരങ്ങളും ചിഹ്നങ്ങളും. താഴെയുള്ള മലയാളം
ഒരു ജനാലയാണ്, പകരക്കാരനല്ല. രണ്ടും വ്യത്യാസപ്പെട്ടാൽ, ഹീബ്രുവാണ്
ശരി.

## നാമം

നാല്-അക്ഷര നാമം വരുന്നിടത്തെല്ലാം ഞങ്ങൾ **യാഹ്‌വെ** എന്ന്
എഴുതുന്നു — അതിന്റെ സ്ഥാനത്ത് ഒരു സ്ഥാനപ്പേരുമില്ല, ഒരു സാമാന്യ
പദവുമില്ല. ഞങ്ങൾ **യഹോവ** (സങ്കര രൂപം) എഴുതുന്നില്ല,
**കർത്താവ്** (സ്ഥാനപ്പേര് — നാമമല്ല) എഴുതുന്നില്ല, നാമത്തിന്റെ
സ്ഥാനത്ത് **ദൈവം** വെക്കുന്നുമില്ല. നാമം ഉള്ളതുപോലെ നിൽക്കുന്നു,
എല്ലായിടത്തും — നാമം എവിടെയെന്ന് എപ്പോഴും കാണാവുന്നതിനായി.

## ആലെഫ്-താവ് — ⟨את⟩

മലയാള വാക്യങ്ങളിൽ **⟨את⟩** നിലനിർത്തിയിരിക്കുന്നത് നിങ്ങൾ
കാണും. ഹീബ്രുവിൽ אֵת എന്നത് കർമ്മത്തിലേക്ക് വിരൽ ചൂണ്ടുന്ന ചെറിയ
പദമാണ്. മലയാളത്തിൽ അതിന് തുല്യപദമില്ല, മിക്ക വിവർത്തനങ്ങളും
അതിനെ നിശ്ശബ്ദമായി നീക്കുന്നു. ഞങ്ങൾ അതിനെ ബ്രാക്കറ്റിൽ
കാണാവുന്നതായി നിലനിർത്തുന്നു — കാരണം അത് ഭാഷയുടെ ഘടനയുടെ
ഭാഗമാണ്. മായ്ക്കുന്നതിനു പകരം, അതിന്റെ സാന്നിധ്യം കാണിക്കുന്നതാണ്
ഞങ്ങൾ തിരഞ്ഞെടുക്കുന്നത്.

## ⟨ബ്രാക്കറ്റി⟩നുള്ളിലെ പദങ്ങൾ

⟨ഇത്തരം⟩ ബ്രാക്കറ്റുകൾ **ഹീബ്രുവിൽ ഇല്ലാത്ത** പദങ്ങളെ
അടയാളപ്പെടുത്തുന്നു — മലയാള വാക്യം നിൽക്കാൻ വേണ്ട ചേർപ്പുകൾ.
അടയാളമില്ലാതെ കലർത്തുന്നതിനു പകരം ഞങ്ങൾ അവയെ ബ്രാക്കറ്റിൽ
വെക്കുന്നു — മൂല ഹീബ്രു പദങ്ങളും മലയാളത്തിന്റെ ആവശ്യത്തിനു
ചേർന്ന പദങ്ങളും എപ്പോഴും വേർതിരിച്ചറിയാവുന്നതിനായി.

## നാമങ്ങളും സ്ഥാനപ്പേരുകളും

പരിശുദ്ധനെ സൂചിപ്പിക്കുന്ന ഹീബ്രു പദങ്ങൾ — **എലോഹീം**, **ഏൽ**,
**ശദ്ദായ്**, **അദോനായ്**, **യാഹ്** — അവയുടെ ഉച്ചാരണപ്രകാരം
എഴുതപ്പെടുന്നു. എല്ലാം ഒരൊറ്റ പദത്തിലേക്ക് ഞെരുക്കുന്നില്ല;
ഓരോന്നും അതിന്റേതായ ഭാരം വഹിക്കുന്നു. വ്യക്തി-സ്ഥല നാമങ്ങളും
ഹീബ്രു രൂപം പിന്തുടരുന്നു: അവ്രാഹാം, യിത്സാക്, യാക്കോവ്, മോശെ,
യെരൂശാലയിം.

## അടയാളപ്പെടുത്തിയ പദങ്ങൾ

- **ഹെസെദ്** (חֶסֶד) — ഉടമ്പടിയുടെ വിശ്വസ്ത സ്നേഹം. വെറും "ദയ"
  അല്ല, വെറും "സ്നേഹം" അല്ല. ഒരു മലയാള പദത്തിനും അതിനെ മുഴുവൻ
  വഹിക്കാനാവില്ല.
- **ശെഓൽ** (שְׁאוֹל) — മരിച്ചവരുടെ സ്ഥലം, ഹീബ്രു പറയുന്നതുപോലെ.
  "നരകം" അല്ല.
- **നെഫെശ്**, **റൂഅഖ്**, **കാവോദ്** — സന്ദർഭാനുസൃതം (ജീവൻ
  അല്ലെങ്കിൽ ജീവിതം, ആത്മാവ് അല്ലെങ്കിൽ കാറ്റ്, മഹത്വം അല്ലെങ്കിൽ
  ഭാരം) — ഒരൊറ്റ പദത്തിൽ ആണിയടിക്കുന്നില്ല.

## ഓരോ വാക്യവും അതിന്റേതായ വെളിച്ചത്തിൽ

ഓരോ വാക്യത്തിന്റെയും വിവർത്തനം അത് അതിന്റെ സ്ഥാനത്ത്
പറയുന്നതുപോലെയാണ് — എലോഹീം ഏകനാണെന്ന ഹീബ്രു വിശ്വാസത്തിൽ
വായിക്കപ്പെടുന്നു. പിന്നീട് വന്ന ഉപദേശങ്ങൾ ചേർക്കപ്പെടുന്നില്ല;
കഥയുടെ അവസാനം അതിന്റെ തുടക്കത്തിൽ വായിക്കപ്പെടുന്നില്ല. പദങ്ങൾ
അവയുടെ സ്ഥാനത്ത് വഹിക്കുന്ന അർത്ഥം ഒഴുകാൻ അനുവദിക്കുന്നതാണ് —
ലക്ഷ്യം.

## ഫയലുകളുടെ ഘടന

ഒരു വാക്യം, ഒരു ഫയൽ: വാക്യം സ്വയം, ഒപ്പം ഓരോ പദത്തിന്റെയും
അർത്ഥം ഹീബ്രുവിന്റെ അരികിൽ — ഓരോ ഹീബ്രു പദവും അതിന്റെ മലയാള
പദത്തിന് എതിരെ വായിക്കാവുന്നതിനായി.
